# Forma examples

This directory is the reviewable source corpus used to exercise Forma's
descriptor, elaboration, and artifact pipeline. Lisp programs live in fenced
blocks inside Markdown so an example can explain its intent beside the source.

The examples deliberately span unrelated domains. They are conformance inputs,
not a vocabulary baked into either engine.

The [market desk](market-desk/README.md) example translates an Effect market API
into Forma schemas, services, and layers, with generated TypeScript and a tested
HTTP adapter.
