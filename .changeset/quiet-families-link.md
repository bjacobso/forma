File-module libraries can declare slash-qualified helpers and forms, validate nested semantic reference holes, and project private nested child families with their defining module's helpers. Existing successful computed single-child IR values remain supported. No previously valid program is intended to newly error; collisions involving newly legal qualified bindings use the existing duplicate-declaration or duplicate-import diagnostics. The polymorphic `nil?` helper now has an ordinary HM scheme (`a -> Bool`). Full connectors checking remains blocked by the runtime semantics of `some`, which returns a callback result or nil rather than Bool.
